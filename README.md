# 🌾 VVT — Vivasaaya Vaniga Thalam

**Agricultural Commerce Platform | Connect Demand. Aggregate Supply. Move Produce.**

VVT is a digital agricultural marketplace that connects farmers directly with verified buyers, aggregates fragmented farm supply, and coordinates logistics for transparent, efficient produce trading.

## 🚀 Features

### Four Core Layers

| Layer | Description |
|-------|-------------|
| 📊 **Discover Price** | Transparent market prices and active buyer offers |
| 🤝 **Find Buyer** | Smart matching algorithm connecting farmers with verified buyers |
| 📦 **Aggregate Supply** | Combine fragmented farm supply into one consolidated order |
| 🚛 **Move Produce** | Coordinated logistics with real-time GPS tracking |

### User Roles

- **👨‍🌾 Farmers** - List harvest, discover prices, find buyers, track deliveries
- **🏢 Buyers** - Post requirements, view supply network, track orders
- **🚚 Transporters** - View assigned deliveries, optimize routes
- **👤 Admin** - Verification and platform control

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| Backend | Node.js, Express.js |
| Database | SQLite3 |
| Maps | Leaflet.js, OpenStreetMap |
| Authentication | JWT, bcryptjs |
